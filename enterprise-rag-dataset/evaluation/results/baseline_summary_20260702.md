## Embedding 迁移故障与修复

Onyx 创建 E5 新索引后，文件连接器沿用了增量检查点。任务显示扫描 30 份文档，但实际为 `new_docs=0`、`total_chunks=0`，导致新索引为空。即使触发 `from_beginning=true`，文件去重逻辑仍跳过已有文件。

修复方法：通过文件连接器更新接口原位替换 30 个文件 ID，在保持 Document Set 和 Agent 绑定不变的前提下触发重新摄取。最终索引任务记录为：

- `total_docs_indexed=30`
- `new_docs_indexed=30`
- `total_chunks=30`
- `status=SUCCESS`

此外记录到 E5 首次并发冷启动会导致请求超时；模型常驻内存后，稳态检索延迟恢复至约 0.3 秒。后续生产化需要增加启动预热与健康检查。
