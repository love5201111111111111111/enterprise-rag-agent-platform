# 事故复盘：订单查询延迟升高（2026-05-08）

## 摘要

14:20 至 14:51，订单查询 API P95 从 180ms 上升至 2.4s，创建订单未受影响。影响约 36 个企业租户，事件等级 P1。

## 根因

报表团队在生产执行无时间范围的导出查询，扫描订单明细表并占用大量 I/O。该服务账号误继承了交互式报表权限，且查询超时设置为 30 分钟。

## 处置

14:29 暂停报表任务；14:35 临时限制报表账号并发；14:44 缓存命中率恢复；14:51 指标稳定。事故期间没有重启数据库，也没有终止核心交易。

## 改进

报表查询迁移到只读副本；强制要求时间范围不超过 31 天；默认超时调整为 60 秒；服务账号权限从共享角色中拆分。增加“单查询读取行数”和只读副本延迟告警。
