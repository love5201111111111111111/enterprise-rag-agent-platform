# 访问控制与生产权限规范

访问遵循最小权限、默认拒绝和职责分离。员工使用个人账号，禁止共享账号。生产控制台和堡垒机必须启用 MFA。

普通研发默认无生产写权限，可申请最长 4 小时的临时权限。申请必须包含工单、操作范围和回滚计划。高风险操作由审批人和执行人分离。

服务账号只能用于机器调用，不允许交互登录。权限每季度复核；员工转岗当天调整权限，离职账号在 30 分钟内禁用。

租户数据访问必须携带租户上下文并写入审计日志。支持人员只能访问处理工单所需的数据。任何跨租户查询都需要安全审批，并采用脱敏结果。

发现凭据暴露时，立即吊销或轮换密钥、检查最近使用记录并通知安全团队。仅删除聊天消息不构成完成处置。
